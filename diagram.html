⚙️ Logic Layer & Managers

Vanilla JavaScript · per page logic + shared functions · no backend frameworks

  • Authentication Manager – login() / register() / logout() · read/write sessionStorage + localStorage · session state: isLoggedIn, loggedUser, loginTime · protected route guard (dashboard redirect) · checkAuth() on page load
  • Dashboard Manager – initChart() (Chart.js line graph – weekly progress) · progressBtn & eventsBtn modals · external resources (YouTube cards, Google Form iframe/new tab)
  • Event Module – Workshops · Internship fair · Cultural fest · modal popup with dynamic event listing · static curated event data (no server)
  • Form Handler – validateInput() · email regex · password match & min length (6) · escapeHtml() sanitization · redirect after successful register/login
  • Notification System – success/error messages inline · auto-dismiss after timeout · color-coded (error red / success green)
  • Page Initialization & Routing – DOMContentLoaded listener → checkAuth() for protected pages → load session user data → addFloatingOrbs() UI enhancements

💾 Data Persistence – Web Storage API

Browser Storage – pure client-side persistence · no server, no database

sessionStorage
isLoggedIn, loggedUser, loginTime
survives page reload (tab session)
localStorage
registeredUser_[email]
JSON: { name, email, registeredOn } · persistent across browser close
Read/Write operations: getItem() / setItem() / removeItem() · session & local managed by Authentication Manager + optional demo users.
Protected routes: dashboard only accessible if isLoggedIn === true → else redirect to login.

🔐 Authentication Flow & Protected Routes

Login simulation
login(username, password) → checks localStorage registered users, sets sessionStorage: isLoggedIn=true, stores user. Dashboard redirect.
Register flow
Stores in localStorage under key registeredUser_{email}. Auto redirect to login page after success.
Route guard
On dashboard.html load → checkAuth() verifies sessionStorage. If not logged in → redirect to login.html. Same for any protected page.
Event Module data (static): workshops, internship fair, cultural fest – modal popup with dynamic listing
Demo credentials hint: login.html shows test@student.com / demo123
