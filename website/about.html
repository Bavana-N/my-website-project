ℹ️ About This Project

The Student Portal is a modern web application designed to help students manage their academic activities efficiently. It provides a centralized platform to track courses, assignments, and overall progress.

⚙️ Technologies

HTML5, CSS3, JavaScript (ES6) for frontend development. Responsive design with modern UI/UX principles.

✨ Pure frontend

🚀 Methodology

Agile methodology was followed by dividing the project into smaller modules — sprints, daily standups, and iterative feedback.

📌 Scrum framework

🔄 CI/CD Process

Integrated with GitHub for version control and Jenkins for automation (simulated pipeline). Ensures continuous delivery.

⚡ DevOps ready

🎯 Objective

To create a simple, user-friendly system for managing student activities with a focus on agile learning and progress tracking.

🎓 Student-first
💡 Built with Agile Mindset — Each feature (Login, Register, Dashboard, Progress Charts) was delivered in iterative cycles, ensuring quick feedback and continuous improvement.
